直流电阻网络求解器

改进节点法（MNA）· 支持浮地电压源 · 节点 0 为参考地

网表输入

输入格式说明
  • R 名称 节点1 节点2 欧姆值 —— 电阻，欧姆值必须为正数。
  • V 名称 正端节点 负端节点 伏特值 —— 独立直流电压源，两端均可不接地。
  • 节点为不小于 0 的整数，节点 0 为地；空行与以 # 开头的行会被忽略。
  • 电流正方向为沿元件输入方向：电阻取节点1 → 节点2；电压源取正端 → 负端。

输入错误

    节点电压

    节点电压 (V)

    元件电流（沿输入方向）

    元件类型方向电流 (A)

    负值表示实际电流方向与输入方向相反；电压源电流方向为正端 → 负端。
